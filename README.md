# SigerSync: Portal Wisata Digital Terintegrasi

## Deskripsi Proyek

SigerSync adalah platform berbasis **Service-Oriented Architecture (SOA)** yang menyajikan informasi lengkap mengenai destinasi wisata di Provinsi Lampung.

### Kategori Wisata
1. **Wisata Alam**: Pantai Gigi Hiu, Pahawang, Gunung Pesagi, Rajabasa
2. **Wisata Budaya**: Museum Lampung, Masyarakat Adat Saibatin/Pepadun
3. **Wisata Edukasi**: Taman Nasional Way Kambas

## Arsitektur Sistem

- **Backend (NestJS)**: API Service Layer
- **CMS Admin (NextJS)**: Management Layer
- **Mobile App (React Native)**: User Layer
